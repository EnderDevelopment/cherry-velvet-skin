# Minecraft Skin Texture

Cherry Velvet Skin is a pixel-art Minecraft skin texture source with burgundy curls, cherry-red highlights, a warm-toned face, pink clothing, and cream and gold accents. The artwork is arranged on a 64×64 skin texture canvas for a classic-style character; the included file is SVG, not a ready-to-import PNG.

## Install

1. Download `assets/textures/burgundy-curly-skin.svg` from the repository.
2. Open the SVG in an image editor that supports SVG, such as Inkscape.
3. Export it as a transparent PNG at exactly 64×64 pixels. Keep the canvas size unchanged.
4. Before importing, check the exported texture in a Minecraft skin editor to confirm its UV mapping and appearance.

## Use

1. In Minecraft Bedrock Edition, open Dressing Room and choose to create or edit a character.
2. Select the option to import a skin, then choose the exported PNG.
3. Review the result in the game. If the texture does not map as expected, correct its layout in a skin editor before importing it again.
